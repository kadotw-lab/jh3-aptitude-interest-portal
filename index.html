Q1. 什麼是百分等級 (PR 值)？分數高低代表什麼？
PR 值（百分等級）代表在同年齡的學生常模群體中，孩子的成績超越了多少百分比的受試者。
‧ PR 75 以上：代表優於 75% 的同齡孩子，屬於該項能力的「強勢潛能」，學習此類知識時通常吸收快、領悟力強。
‧ PR 25 ~ 74：代表落在「平均發展水準」，大部分學生均在此區間，只要持之以恆均能穩定發展。
‧ PR 25 以下：代表該項潛能目前「較少被開發或運用」，不代表未來無法進步，可透過後天刻意練習建立基礎信心。
Q2. 孩子的「性向」與「興趣」測驗結果不一樣，該怎麼辦？
這在國中階段是非常普遍且正常的現象！
‧ 性向是「能力（學得快不快）」；興趣是「熱情（喜不喜歡、想不想做）」。
‧ 相符時（事半功倍）：如果性向與興趣皆推薦同一群類，可列為升學的首選優先考慮。
‧ 有能力但沒興趣（性向高、興趣低）：孩子資質很好，但可能因為「尚未接觸該生活情境」或「缺乏引發成就感的經驗」。建議多帶孩子參訪實際工作環境、參觀技術院校實習工場，常常能點燃孩子的學習好奇心！
‧ 有興趣但能力稍弱（興趣高、性向普通）：強烈的內在熱忱往往是堅持到底的最大動力！若孩子真的很喜歡，只要付出更多練習與良好學習策略，依然能夠在專業領域中發光發熱。
Q3. 該選擇「普通高中」還是「技術型高中（高職）」？
‧ 選擇普通高中：適合學科（國、英、數、社、自）基礎較好、喜愛抽象概念與理論探索、對特定職業專長尚未有明確偏好，希望再多探索三年後升讀一般大學的孩子。
‧ 選擇高職（專業技術型高中）：適合動手實作動機強、不喜歡純紙筆理論背誦、對於特定職群（如資訊、餐飲、商業、電機、設計等）已有明顯喜好的孩子。高職亦可透過科技校院繁星計畫或統測升讀頂尖科技大學。
Q4. 輔導室對家長的三大建議：傾聽、陪伴、不設限
1. 不將測驗當作「終身標籤」：測驗只是一面鏡子，反映現階段的傾向，孩子的潛能會隨著年齡與閱歷持續成長。
2. 避免以成人的就業焦慮加諸孩子：尊重孩子的獨特性，協助孩子找到能發揮其長處的舞台，而非只看單一熱門科系。
3. 預約個別晤談：若您或孩子對升學進路有疑問，歡迎隨時向學校輔導室預約生涯輔導諮詢！
