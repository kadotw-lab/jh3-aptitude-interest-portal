# 國三美班 學生興趣測驗與性向測驗家長查詢系統

專為「國三美班」家長設計的適性輔導與生涯探索查詢系統。家長輸入學生之「座號」與「身分證字號」，即可查閱個人化測驗報表，並提供完整的測驗結果交叉解讀與升學群科導引。

---

## 🌟 核心特色與功能

1. **家長身分驗證**：
   - 支援「座號 (1 ~ 47)」與「身分證字號末3碼 (亦相容完整10碼)」驗證登入，家長輸入更輕鬆便捷。
   - 內建 43 位全班學生之完整真實測驗資料庫，保護學生個人隱私。
   - 提供「測試帳號快捷填入」按鈕，方便老師或家長一鍵體驗。

2. **核心落點交叉分析 (焦點核心)**：
   - **事半功倍群類（黃金契合）**：自動比對「性向推薦」與「興趣推薦」皆相符之重疊群類，高亮呈現最佳發展方向。
   - **潛能優勢群類（性向突出）**：孩子學習領悟快、理解能力強之類群。
   - **熱忱偏好群類（興趣突出）**：孩子主觀熱忱高、最具投入意願之類群。
   - **輔導室關懷提醒**：針對興趣量表作答保守或尚在探索期之需關懷學生，提供溫暖正向的輔導建議。

3. **八大能力性向測驗視覺化**：
   - 八大分測驗：語文、數學(數感)、科學推理、觀察、邏輯推理、空間關係、美感判斷、創意潛能。
   - 繪製 **PR 值（百分等級）直條圖**，標示 PR 75 頂尖優勢潛能線。
   - 每項能力皆有白話文生活能力意義解析。

4. **Holland RIASEC 興趣光譜分析**：
   - 六大興趣類型：實用型(R)、研究型(I)、藝術型(A)、社會型(S)、企業型(E)、事務型(C)。
   - 繪製 **六角形雷達圖**，直觀呈現興趣分化程度。
   - 自動運算產生 **前三大優勢代碼（如 A-S-E）**，提供特質詳解與典型職業推薦。

5. **高職 15 群科與普通高中完整導航庫**：
   - 完整收錄：機械群、動力機械群、電機電子群、化工群、土木建築群、商業管理群、外語群、設計群、農業群、食品群、餐旅群、家政群、水產群、海事群、藝術群、一般/普通高中。
   - 支援 **即時關鍵字搜尋** 與 **類群標籤篩選**。
   - 自動高亮符合該生推薦之類群，並列出對應之高職科別清單。

6. **家長陪跑手冊與升學常見問題 (FAQ)**：
   - 「如何解讀百分等級 PR 值？」
   - 「性向與興趣不一致時該如何引導？」
   - 「如何抉擇普通高中與技術型高中（高職）？」
   - 「輔導室建議的三大陪伴心法：傾聽、陪伴、不設限」。

7. **友善列印與 PDF 存檔排版**：
   - 點擊「列印 / 存為PDF」即可輸出格式乾淨正式的個人化成績報表。

## 🚀 如何使用與開啟

### 方法一：直接點擊批次檔（最推薦）
- 在資料夾中直接雙擊點擊 **`啟動查詢網站.bat`**。
- 系統將自動啟動本地伺服器並在您的預設瀏覽器中開啟系統頁面。

### 方法二：直接用瀏覽器開啟
- 在資料夾中直接雙擊 **`index.html`**。
- 本系統所有資料、樣式與 Chart.js 圖表引擎均已本地化打包，即使在無網路環境下亦可完整離線運作！

---

## 📂 檔案目錄架構

- **`index.html`**：家長查詢入口與個人化報表主網頁
- **`style.css`**：現代化響應式 UI 設計、卡片漸層與列印專屬樣式
- **`app.js`**：前端交互邏輯、登入驗證、交集運算、Chart.js 圖表渲染
- **`data.js`**：43位學生測驗資料與15群科/Holland說明元數據
- **`chart.min.js`**：本地離線 Chart.js 圖表庫
- **`start_server.py`**：輕量本地 Web 伺服器啟動腳本
- **`啟動查詢網站.bat`**：Windows 一鍵啟動快捷檔
- **`帳號密碼.txt`**：原始學生座號、姓名與身分證字號
- **`性向測驗.jpg` / `興趣測驗.jpg`**：原始測驗成績單掃描檔
- **`測驗說明1~4.jpg`**：原始測驗說明指南與群科對應表
